# Coerce glue_data() output to character

Coerce glue_data() output to character

## Usage

``` r
glue_data_chr(.x, ...)
```

## Arguments

- .x:

  `<vec>` vector to pass to glue_data()

- ...:

  dots to pass to glue function

## Value

`<chr>` vector
